# 资讯页接口文档

## 文档说明

- 页面对象：小程序资讯列表页、资讯详情页
- 服务前缀：`/api/v1/app`
- 认证方式：`Authorization: Bearer <token>`
- 返回结构：统一为 `ApiResponse<T>`
- 分页结构：列表接口 `data` 为 `PageResponse<T>`

## 接口总览

| 页面区域 | 接口 | 用途 |
|---|---|---|
| 资讯列表 | `GET /api/v1/app/content/articles` | 获取资讯卡片列表 |
| 资讯详情 | `GET /api/v1/app/content/articles/{id}` | 获取资讯正文详情 |
| 收藏/取消收藏 | `POST /api/v1/app/interaction/favorites` | 收藏或取消收藏资讯 |
| 浏览量上报 | `POST /api/v1/app/interaction/browse-histories` | 上报资讯阅读记录 |

## 1. 资讯列表

### 接口

```http
GET /api/v1/app/content/articles
```

### 用途

- 资讯列表页
- 资讯搜索结果页

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| page | number | 否 | 页码，默认 `1` |
| size | number | 否 | 每页条数，默认 `20` |
| keyword | string | 否 | 标题、来源、摘要关键字搜索 |

### 返回关键字段

| 字段 | 类型 | 说明 |
|---|---|---|
| id | number | 资讯 ID |
| title | string | 标题 |
| summary | string | 摘要 |
| coverUrl | string | 封面图 |
| authorName | string | 作者 |
| source | string | 来源 |
| tags | string[] | 标签 |
| viewCount | number | 阅读量 |
| favoriteCount | number | 收藏数 |
| favorited | boolean | 当前用户是否已收藏 |
| publishedAt | string | 发布时间 |

### 请求示例

```http
GET /api/v1/app/content/articles?page=1&size=10&keyword=病理
Authorization: Bearer <token>
```

## 2. 资讯详情

### 接口

```http
GET /api/v1/app/content/articles/{id}
```

### 用途

- 资讯详情页
- 展示标题、正文、来源、阅读量、收藏态

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| id | number | 是 | 资讯 ID |

### 返回关键字段

| 字段 | 类型 | 说明 |
|---|---|---|
| id | number | 资讯 ID |
| title | string | 标题 |
| summary | string | 摘要 |
| coverUrl | string | 封面图 |
| content | string | 正文内容 |
| authorName | string | 作者 |
| source | string | 来源 |
| tags | string[] | 标签 |
| viewCount | number | 阅读量 |
| favoriteCount | number | 收藏数 |
| favorited | boolean | 当前用户是否已收藏 |
| publishedAt | string | 发布时间 |

### 请求示例

```http
GET /api/v1/app/content/articles/101
Authorization: Bearer <token>
```

## 3. 收藏/取消收藏

### 接口

```http
POST /api/v1/app/interaction/favorites
```

### 用途

- 资讯详情页点击收藏
- 资讯列表页点击收藏

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| resourceType | string | 是 | 固定传 `article` |
| resourceId | number | 是 | 资讯 ID |
| favorited | boolean | 是 | `true` 表示收藏，`false` 表示取消收藏 |

### 请求示例

```json
{
  "resourceType": "article",
  "resourceId": 101,
  "favorited": true
}
```

## 4. 浏览量上报

### 接口

```http
POST /api/v1/app/interaction/browse-histories
```

### 用途

- 进入资讯详情页时上报阅读
- 驱动资讯 `viewCount` 统计

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| resourceType | string | 是 | 固定传 `article` |
| resourceId | number | 是 | 资讯 ID |
| source | string | 否 | 来源页面标识，如 `article-detail` |
| viewCount | number | 否 | 本次累加次数，通常传 `1` |

### 请求示例

```json
{
  "resourceType": "article",
  "resourceId": 101,
  "source": "article-detail",
  "viewCount": 1
}
```

## 页面对接建议

### 列表页

1. 调用 `GET /api/v1/app/content/articles`
2. 渲染标题、摘要、来源、阅读量、收藏数、收藏态
3. 点击卡片跳转 `GET /api/v1/app/content/articles/{id}`

### 详情页

1. 调用 `GET /api/v1/app/content/articles/{id}`
2. 页面进入后调用 `POST /api/v1/app/interaction/browse-histories`
3. 点击收藏时调用 `POST /api/v1/app/interaction/favorites`

## 当前边界说明

- 当前后端已补齐用户端资讯列表、资讯详情两个正式接口。
- 资讯已接入现有收藏、浏览互动模型，`resourceType` 使用 `article`。
- 当前未提供资讯评论数、评论列表、评论详情接口。
- 当前未提供资讯分享记录接口，如前端仅做客户端分享按钮展示，可先不依赖后端分享写接口。
