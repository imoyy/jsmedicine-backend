# 考核大屏前端接入说明

## 适用范围

本文面向管理端前端，覆盖以下页面的接口接入：

- 考核场次列表页
- 考核场次新增/编辑页
- 考核大屏页
- 考核参与明细弹层或列表页
- 考核参与明细导出

大屏后端已切换到“考核场次 + dashboard 聚合接口”模型，不再复用旧的考卷成绩统计接口。

## 基本约定

- 管理端接口前缀：`/api/v1/admin/...`
- 认证方式：`Authorization: Bearer <token>`
- 统一响应结构：`ApiResponse<T>`
- 分页结构：`PageResponse<T>`
- 时间字段格式：ISO date-time，例如 `2026-06-09T17:16:47`

统一响应示例：

```json
{
  "success": true,
  "code": "OK",
  "message": "success",
  "data": {}
}
```

## 一、考核场次管理接口

### 1. 分页查询考核场次

- 方法：`GET`
- 地址：`/api/v1/admin/learning/exam-assessments`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | number | 是 | 页码，从 `1` 开始 |
| `size` | number | 是 | 每页条数 |
| `sort` | string | 否 | 当前支持：`startAtAsc`；不传默认按 `startAt` 倒序 |
| `keyword` | string | 否 | 按考核名称模糊搜索 |
| `assessmentType` | string | 否 | `formal` / `makeup` / `mock` |
| `status` | string | 否 | `not_started` / `in_progress` / `ended` / `cancelled` / `archived` |
| `startAt` | string | 否 | 开始时间下界 |
| `endAt` | string | 否 | 结束时间上界 |

返回字段 `data.records[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 考核场次 ID |
| `assessmentName` | string | 考核名称 |
| `paperId` | number | 关联试卷 ID |
| `paperName` | string | 关联试卷名称 |
| `assessmentType` | string | 考核类型 |
| `status` | string | 当前展示状态 |
| `startAt` | string | 开始时间 |
| `endAt` | string | 结束时间 |
| `expectedStudentCount` | number | 应考人数 |
| `scopeSummary` | object | 范围摘要 |

`scopeSummary` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `provinceCode` | string \| null | 省编码 |
| `cityCode` | string \| null | 市编码 |
| `districtCode` | string \| null | 区编码 |
| `organizationCount` | number | 机构数量 |
| `explicitStudentCount` | number | 指定学员数量 |
| `expectedStudentCount` | number | 应考人数 |

### 2. 查询考核场次详情

- 方法：`GET`
- 地址：`/api/v1/admin/learning/exam-assessments/{id}`

适用于编辑页回填。

返回字段比列表多出：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `provinceCode` | string \| null | 地区范围：省编码 |
| `cityCode` | string \| null | 地区范围：市编码 |
| `districtCode` | string \| null | 地区范围：区编码 |
| `organizationIds` | number[] | 机构范围 |
| `explicitStudentIds` | number[] | 指定学员范围 |

### 3. 新增考核场次

- 方法：`POST`
- 地址：`/api/v1/admin/learning/exam-assessments`
- `Content-Type`：`application/json`

请求体：

```json
{
  "assessmentName": "2026 年 6 月针灸理论考核",
  "paperId": 51,
  "assessmentType": "formal",
  "startAt": "2026-06-10T09:00:00",
  "endAt": "2026-06-10T10:00:00",
  "provinceCode": "330000",
  "cityCode": "330100",
  "districtCode": "330106",
  "organizationIds": [151],
  "studentIds": [239, 242]
}
```

接入约束：

- 首版地区范围只支持单条省市区链路。
- `provinceCode/cityCode/districtCode`、`organizationIds`、`studentIds` 可以叠加。
- 不能所有范围都为空，否则后端会报错。
- 创建成功后直接返回详情结构。

### 4. 修改考核场次

- 方法：`PUT`
- 地址：`/api/v1/admin/learning/exam-assessments/{id}`

请求体与新增一致。

接入约束：

- 只有 `not_started` 状态的考核允许编辑。
- `cancelled` 和 `archived` 状态不允许修改。

### 5. 更新考核场次状态

- 方法：`PATCH`
- 地址：`/api/v1/admin/learning/exam-assessments/{id}/status`

请求体：

```json
{
  "status": "cancelled"
}
```

当前只允许传：

- `cancelled`
- `archived`

## 二、考核大屏接口

### 1. 查询大屏聚合数据

- 方法：`GET`
- 地址：`/api/v1/admin/statistics/exam-assessments/{id}/dashboard`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `dimension` | string | 否 | 分布维度，支持 `province` / `city` / `district` / `organization`，默认 `province` |
| `bucketMinutes` | number | 否 | 趋势时间桶，支持 `5` / `10` / `30`，默认 `5` |

返回结构：

```json
{
  "overview": {},
  "paperStructure": {},
  "distribution": [],
  "trend": [],
  "latestEvents": []
}
```

### 2. overview 字段说明

`overview` 是顶部卡片和头部信息的数据源。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assessmentId` | number | 考核场次 ID |
| `assessmentName` | string | 考核名称 |
| `paperId` | number | 试卷 ID |
| `paperName` | string | 试卷名称 |
| `assessmentType` | string | `formal` / `makeup` / `mock` |
| `status` | string | `not_started` / `in_progress` / `ended` / `cancelled` / `archived` |
| `startAt` | string | 开始时间 |
| `endAt` | string | 结束时间 |
| `serverTime` | string | 服务端当前时间 |
| `countdownSeconds` | number | 距离开始或结束的倒计时秒数 |
| `expectedCount` | number | 应考人数 |
| `actualAttendCount` | number | 实考人数 |
| `notStartedCount` | number | 未开始人数 |
| `absentCount` | number | 缺考人数 |
| `inProgressCount` | number | 考试中人数 |
| `completedCount` | number | 已完成人数 |
| `passCount` | number | 合格人数 |
| `failCount` | number | 不合格人数 |
| `passRate` | number | 合格率，百分比数值，如 `66.67` |
| `averageScore` | number | 平均分 |
| `highestScore` | number | 最高分 |
| `lowestScore` | number | 最低分 |

口径必须固定按下面展示，不要自行改中文名：

- `expectedCount` -> 应考人数
- `actualAttendCount` -> 实考人数
- `notStartedCount` -> 未开始人数
- `absentCount` -> 缺考人数
- `inProgressCount` -> 考试中人数
- `completedCount` -> 已完成人数
- `passCount` -> 合格人数
- `failCount` -> 不合格人数

特别说明：

- 前端不要再使用“未考人数”这个模糊文案。
- `notStartedCount` 定义：考核未结束时，还没进入考试的人数。
- `absentCount` 定义：仅考核结束后统计“从未进入考试”的人数。
- 在考核未结束前，`absentCount` 固定返回 `0`。

### 3. paperStructure 字段说明

`paperStructure` 用于试卷结构、题型分布卡片或图表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `paperId` | number | 试卷 ID |
| `paperName` | string | 试卷名称 |
| `totalScore` | number | 试卷总分 |
| `passScore` | number | 合格分 |
| `durationMinutes` | number | 时长，单位分钟 |
| `questionCount` | number | 总题数 |
| `questionTypeBreakdown` | array | 题型拆分 |

`questionTypeBreakdown[]` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `questionType` | string | 题型枚举，来自后端 `QuestionType` |
| `questionCount` | number | 该题型题目数 |
| `scorePerQuestion` | number | 单题分值 |
| `totalScore` | number | 该题型总分 |

### 4. distribution 字段说明

`distribution` 用于地区或机构分布图。

每一项字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dimensionCode` | string | 当前维度编码 |
| `dimensionName` | string | 当前维度名称 |
| `expectedCount` | number | 应考人数 |
| `actualAttendCount` | number | 实考人数 |
| `absentCount` | number | 缺考人数 |
| `inProgressCount` | number | 考试中人数 |
| `completedCount` | number | 已完成人数 |
| `passCount` | number | 合格人数 |
| `failCount` | number | 不合格人数 |
| `passRate` | number | 合格率 |
| `averageScore` | number | 平均分 |

维度说明：

- `dimension=province` 时：按省统计
- `dimension=city` 时：按市统计
- `dimension=district` 时：按区县统计
- `dimension=organization` 时：按机构统计

### 5. trend 字段说明

`trend` 用于折线图或面积图。

每一项字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `bucketTime` | string | 时间桶节点 |
| `actualAttendCount` | number | 截止该时间点已进入人数 |
| `inProgressCount` | number | 截止该时间点仍在作答人数 |
| `completedCount` | number | 截止该时间点已完成人数 |
| `passCount` | number | 截止该时间点合格人数 |
| `failCount` | number | 截止该时间点不合格人数 |

前端接入建议：

- 默认传 `bucketMinutes=5`
- 数据量较多时可切换 `10` 或 `30`
- 横轴建议直接使用 `bucketTime`

### 6. latestEvents 字段说明

`latestEvents` 用于右侧动态事件流。

每一项字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` | number | 事件 ID |
| `eventType` | string | 事件类型 |
| `studentId` | number | 学员 ID |
| `studentName` | string | 学员姓名 |
| `organizationName` | string | 机构名称 |
| `provinceCode` | string | 省编码 |
| `cityCode` | string | 市编码 |
| `districtCode` | string | 区编码 |
| `eventTime` | string | 事件时间 |
| `description` | string | 事件描述 |

首版只保证这四类强业务事件：

- `enter`
- `submit`
- `timeout`
- `forced_submit`

以下事件类型虽然有预留枚举，但首版不要对业务承诺“完整实时监控”：

- `disconnect`
- `reconnect`
- `abnormal_exit`

## 三、参与明细接口

### 1. 分页查询参与明细

- 方法：`GET`
- 地址：`/api/v1/admin/statistics/exam-assessments/{id}/participants`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | number | 是 | 页码，从 `1` 开始 |
| `size` | number | 是 | 每页条数 |
| `status` | string | 否 | 参与状态过滤 |
| `dimensionCode` | string | 否 | 地区或机构编码过滤 |
| `keyword` | string | 否 | 支持姓名、手机号、机构名模糊匹配 |

返回字段 `data.records[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `studentId` | number | 学员 ID |
| `studentName` | string | 学员姓名 |
| `mobile` | string | 手机号 |
| `maskedIdCardNo` | string | 脱敏证件号，来自快照 |
| `provinceCode` | string | 省编码 |
| `provinceName` | string | 省名称 |
| `cityCode` | string | 市编码 |
| `cityName` | string | 市名称 |
| `districtCode` | string | 区编码 |
| `districtName` | string | 区名称 |
| `organizationId` | number \| null | 机构 ID |
| `organizationName` | string | 机构名称 |
| `enteredAt` | string \| null | 进入考试时间 |
| `submittedAt` | string \| null | 交卷时间 |
| `status` | string | 参与状态 |
| `score` | number \| null | 得分 |
| `passed` | boolean \| null | 是否合格 |

`status` 可能值：

- `not_started`
- `absent`
- `in_progress`
- `submitted`
- `forced_submitted`
- `timed_out`

说明：

- `not_started`：考核未结束且从未进入
- `absent`：考核已结束且从未进入
- 其他值直接来自考试记录状态

### 2. 导出参与明细

- 方法：`GET`
- 地址：`/api/v1/admin/statistics/exam-assessments/{id}/participants/export`

请求参数与 `participants` 一致：

- `status`
- `dimensionCode`
- `keyword`

返回：

- `Content-Type`：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- `Content-Disposition`：附件下载

导出列固定为：

- 学员ID
- 姓名
- 手机号
- 脱敏证件号
- 省编码
- 省份
- 市编码
- 城市
- 区编码
- 区县
- 机构ID
- 机构名称
- 开始答题时间
- 交卷时间
- 当前状态
- 得分
- 是否合格

## 四、前端页面装配建议

### 1. 推荐页面请求顺序

列表页：

1. 先调 `GET /api/v1/admin/learning/exam-assessments`
2. 选中某个考核后跳转大屏页，带上 `assessmentId`

大屏页：

1. 先调 `GET /dashboard`
2. 再调 `GET /participants?page=1&size=20`
3. 用户切换维度时，仅重刷 `dashboard`
4. 用户切换筛选条件时，重刷 `participants`

### 2. 轮询建议

首版后端不依赖 WebSocket 或 SSE，前端直接轮询即可。

建议：

- 大屏页轮询间隔：`15s`
- 如果页面不可见，可暂停轮询
- 列表明细不建议高频轮询，手动刷新或 `30s` 即可

### 3. 中文文案建议

顶部卡片建议直接使用：

- 应考人数
- 实考人数
- 未开始人数
- 缺考人数
- 考试中人数
- 已完成人数
- 合格人数
- 不合格人数

不要使用：

- 未考人数

## 六、联调注意点

### 1. 大屏页面只认考核场次 ID

不要再拿 `paperId` 直接查大屏。

正确做法：

- 先在考核场次列表选中一条记录
- 再用 `assessmentId` 调大屏接口

### 2. 脱敏证件号来自快照

`participants` 和 `participants/export` 返回的 `maskedIdCardNo` 已经是历史快照字段。

前端不要：

- 再回查当前学员资料拼证件号
- 再做一次自定义脱敏覆盖服务端结果

### 3. 维度筛选值直接用 `dimensionCode`

当前 `participants` 的 `dimensionCode` 过滤是宽匹配：

- 可能匹配省编码
- 可能匹配市编码
- 可能匹配区编码
- 可能匹配机构 ID 字符串

因此前端最佳做法是：

- 从当前 `distribution[]` 里取 `dimensionCode`
- 再原样回传给 `participants`

不要自己推断编码类型。

### 4. 合格率字段是百分比值，不是 0 到 1

例如：

- `66.67` 表示 `66.67%`
- 不是 `0.6667`

前端展示时直接补 `%` 即可，不要再乘 `100`

## 七、已验证链路

本地已完成一轮真实联调验证：

- 管理员登录成功
- 创建单人测试考核成功
- 用户端看到考核成功
- 重复 `enter` 返回同一条考试记录
- 重复 `submit` 返回同一最终结果
- `dashboard`、`participants`、`participants/export` 均成功返回

因此前端可以按本文档直接接入。
