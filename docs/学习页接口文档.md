# 学习页接口文档

## 文档说明

- 页面对象：小程序 `学习` 页面
- 接口范围：当前仓库中已经实现的用户端学习资源接口、互动接口
- 服务前缀：`/api/v1/app`
- 认证方式：`Authorization: Bearer <token>`
- 返回结构：统一为 `ApiResponse<T>`
- 分页结构：列表接口 `data` 为 `PageResponse<T>`

## 页面接口总览

| 页面区域 | 接口 | 用途 |
|---|---|---|
| 大图专题卡片流 | `GET /api/v1/app/learning/topics` | 获取学习页顶部主内容流 |
| 专题详情 | `GET /api/v1/app/learning/topics/{id}` | 获取专题详情及分区预览 |
| 专题分区更多 | `GET /api/v1/app/learning/topics/{id}/sections/{sectionType}` | 获取专题下某个分区完整列表 |
| 学习类资源列表 | `GET /api/v1/app/learning/books` | 获取图书/图文类资源列表 |
| 学习类资源详情 | `GET /api/v1/app/learning/books/{id}` | 获取图书详情 |
| 图书章节详情 | `GET /api/v1/app/learning/books/{bookId}/chapters/{chapterId}` | 获取章节正文 |
| 视频类资源列表 | `GET /api/v1/app/learning/courses` | 获取课程列表 |
| 视频类资源详情 | `GET /api/v1/app/learning/courses/{id}` | 获取课程详情 |
| 视频播放详情 | `GET /api/v1/app/learning/courses/{courseId}/videos/{videoId}` | 获取课程视频详情 |
| 音频类资源列表 | `GET /api/v1/app/learning/podcasts` | 获取播客列表 |
| 音频类资源详情 | `GET /api/v1/app/learning/podcasts/{id}` | 获取播客详情 |
| 收藏/取消收藏 | `POST /api/v1/app/interaction/favorites` | 收藏或取消收藏资源 |
| 浏览量上报 | `POST /api/v1/app/interaction/browse-histories` | 上报资源浏览记录 |
| 学习进度同步 | `POST /api/v1/app/learning/records` | 同步用户学习进度 |

## 1. 专题列表

### 接口

```http
GET /api/v1/app/learning/topics
```

### 用途

- 学习页顶部大图卡片流
- 专题推荐列表

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| page | number | 否 | 页码，默认 `1` |
| size | number | 否 | 每页条数，默认 `20` |
| sort | string | 否 | 排序字段 |
| keyword | string | 否 | 关键字搜索 |

### 请求示例

```http
GET /api/v1/app/learning/topics?page=1&size=10
Authorization: Bearer <token>
```

### 返回关键字段

| 字段 | 类型 | 说明 |
|---|---|---|
| id | number | 专题 ID |
| title | string | 标题 |
| summary | string | 简介 |
| learningRequirements | string | 学习要求/学习说明 |
| coverUrl | string | 封面图 |
| tags | string[] | 标签 |
| viewCount | number | 浏览量 |
| publishedAt | string | 发布时间 |
| favoriteCount | number | 收藏数 |
| favorited | boolean | 当前用户是否已收藏 |

### 返回示例

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "records": [
      {
        "id": 101,
        "title": "中医药知识与技能培训",
        "summary": "专题简介",
        "learningRequirements": "适合入门学习",
        "coverUrl": "https://example.com/topic-cover.jpg",
        "tags": [
          "中医理论"
        ],
        "viewCount": 2000,
        "publishedAt": "2026-06-04T10:00:00",
        "favoriteCount": 76,
        "favorited": true
      }
    ],
    "total": 1,
    "page": 1,
    "size": 10
  }
}
```

## 2. 专题详情

### 接口

```http
GET /api/v1/app/learning/topics/{id}
```

### 用途

- 点击专题卡片进入详情页
- 获取专题基础信息和分区预览

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| id | number | 是 | 专题 ID |

### 返回关键字段

| 字段 | 类型 | 说明 |
|---|---|---|
| id | number | 专题 ID |
| title | string | 标题 |
| summary | string | 简介 |
| learningRequirements | string | 学习要求 |
| coverUrl | string | 封面图 |
| tags | string[] | 标签 |
| viewCount | number | 浏览量 |
| publishedAt | string | 发布时间 |
| favoriteCount | number | 收藏数 |
| favorited | boolean | 是否已收藏 |
| sections | array | 分区预览列表 |

### `sections` 子项字段

| 字段 | 类型 | 说明 |
|---|---|---|
| sectionType | string | 分区类型 |
| sectionLabel | string | 分区名称 |
| total | number | 分区资源总数 |
| hasMore | boolean | 是否还有更多 |
| previewItems | array | 分区预览资源 |

### 分区类型说明

当前后端只支持以下 3 个专题分区：

- `learning`
- `video`
- `audio`

## 3. 专题分区内容列表

### 接口

```http
GET /api/v1/app/learning/topics/{id}/sections/{sectionType}
```

### 用途

- 获取专题下单个分区的完整资源列表

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| id | number | 是 | 专题 ID |
| sectionType | string | 是 | 分区类型：`learning` / `video` / `audio` |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| page | number | 否 | 页码，默认 `1` |
| size | number | 否 | 每页条数，默认 `20` |

### 返回说明

- `learning` 分区映射图书资源
- `video` 分区映射课程资源
- `audio` 分区映射播客资源

返回体为分区资源卡片分页列表，前端应根据 `sectionType` 决定卡片展示样式和点击跳转目标。

## 12. 收藏/取消收藏

### 接口

```http
POST /api/v1/app/interaction/favorites
```

### 用途

- 点击收藏按钮
- 收藏或取消收藏专题、图书、课程、播客

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| resourceType | string | 是 | 资源类型 |
| resourceId | number | 是 | 资源 ID |
| favorited | boolean | 是 | `true` 表示收藏，`false` 表示取消收藏 |

### 请求示例

```json
{
  "resourceType": "topic",
  "resourceId": 101,
  "favorited": true
}
```

### 返回示例

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "resourceType": "topic",
    "resourceId": 101,
    "favoriteCount": 77,
    "favorited": true
  }
}
```

### 推荐资源类型

- `topic`
- `book`
- `course`
- `podcast`

## 14. 学习进度同步

### 接口

```http
POST /api/v1/app/learning/records
```

### 用途

- 同步图书、课程、播客学习进度
- 支撑进度百分比和学习时长展示

### 说明

学习进度请求体应由阅读页、播放页按实际学习行为上报。当前页面首屏展示通常只消费返回结果中的进度字段，不直接依赖这个接口首屏取数。

## 前端页面对接建议

### 页面初始化

1. 页面首屏调用 `GET /api/v1/app/learning/topics`
2. 渲染专题卡片流
3. 使用返回字段直接展示浏览量、收藏数、收藏态

### 点击专题卡片

1. 调用 `GET /api/v1/app/learning/topics/{id}`
2. 渲染专题详情和分区预览
3. 点击分区更多时调用 `GET /api/v1/app/learning/topics/{id}/sections/{sectionType}`

### 点击资源卡片

- 图书跳转 `GET /api/v1/app/learning/books/{id}`
- 课程跳转 `GET /api/v1/app/learning/courses/{id}`
- 播客跳转 `GET /api/v1/app/learning/podcasts/{id}`

### 进入详情页后的写操作

- 调用 `POST /api/v1/app/interaction/browse-histories` 上报浏览
- 点击收藏时调用 `POST /api/v1/app/interaction/favorites`
- 学习行为结束后调用 `POST /api/v1/app/learning/records`

## 当前后端边界说明

这点需要和前端、产品明确：

- 后端当前明确支持的是 `专题 + 图书 + 课程 + 播客`
- 专题分区只支持 `learning / video / audio`
- 代码中没有发现针对页面顶部 `学习 / 视频 / 综合 / 养生` 四个频道 Tab 的独立接口
- 代码中也没有发现“综合”“养生”对应的单独用户端资源类型或频道聚合接口

因此，如果前端要严格按设计稿实现顶部 `综合`、`养生` 两个频道切换，后端目前大概率还缺频道聚合能力，不能默认已具备现成接口。
