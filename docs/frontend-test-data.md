- 接口根地址：`https://api-test.arez.cc.cd`

```http
Authorization: Bearer <accessToken>
```

## 登录示例

管理端登录：

```http
POST https://api-test.arez.cc.cd/api/v1/auth/login
Content-Type: application/json

{
  "username": "td_admin",
  "password": "Admin@123456"
}
```

用户端登录：

```http
POST https://api-test.arez.cc.cd/api/v1/app/auth/login
Content-Type: application/json

{
  "username": "td_user_01",
  "password": "User@123456"
}
```

## 数据命名规则

测试数据统一使用以下前缀，便于列表页搜索和识别：

- 用户、账号、内部类型：`td_`
- 编码、学员编号：`TD_` 或 `TD-`
- 页面可见业务名称：`[TD]`

前端联调时优先搜索 `[TD]`，可以快速定位测试资源。

## 使用注意

- 不要依赖数据库自增 ID，列表接口中先按名称搜索 `[TD]`，再使用接口返回的 ID。
- 当前测试种子里大量 `https://example.com/assets/...`、`https://example.com/live/...` 只是占位数据，用于页面字段联调，不要把它们当成共享联调环境可访问资源。
- 当前只有用户头像已稳定切到 `/api/v1/files/{id}/content`；课程封面、图书封面、播客封面、专题封面、直播封面、专家头像/封面、音视频播放地址等字段，现阶段仍可能是普通 URL 字符串。
- 前端遇到占位媒体地址时，应按“有值即可渲染字段、无法访问不视为接口失败”处理；需要真实可访问素材时，以后端另行提供的真实地址或 `/api/v1/files/{id}/content` 为准。
- 共享联调环境的数据可能被后端按需刷新；前端不要把测试数据当作长期固定状态。
- 遇到接口字段疑问，以 Swagger 的 OpenAPI JSON 为准。
